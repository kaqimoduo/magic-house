# 项目制组织架构系统（React + Vite）

## 功能

- 组织架构图：树状展示组织节点，支持展开/收起，展示负责人、人数、职级、序列。
- 项目进展跟踪：展示项目目标、成员构成、项目进展、项目周期、立项人、审批人等信息。
- 项目编辑抽屉：可直接修改项目名称、分类、进度、周期、立项人、审批人、项目经理、状态文案与项目简介。
- 本地持久化：编辑后的项目信息会保存到浏览器本地，刷新页面不会丢失。
- 恢复默认：支持一键恢复到初始演示数据。

## 启动

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
